# Project Overview
Portfolio forecasting and Investment analysis
A web application that can predict the health of portfolio


## User Types

### Client

A client is a user who will login into applicaton and update his portfolio.

#### Pages and functionalities:

- User login 
- Jwt for session management
- Dashboard
 - Bar Graph 
 - XIRR : can be calculated using formula
 - CAGR : also same
 - Expected Returns : year wise , month wise , 3 year wise , 5 year wise 
 - Past returns
 - Portfolio good or bad by analyzing if the stocks are balanced i.e. large mid or small and allocation of sectors
